# Mock Auth API

Supports:
- Basic Auth
- OAuth 2.0
- JWE Authentication

## Run Locally

npm install
npm start

## Deploy

Upload to GitHub and connect to Render.

## APIs

POST /basic/login
POST /oauth/token
GET /oauth/profile
POST /jwe/login
GET /jwe/profile
GET /health
